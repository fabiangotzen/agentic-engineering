# Bridging to the stronger language

This file describes how to compare a concept with the language that the user knows better.

## Method

- Start with the familiar concept in the stronger language. Then show the difference.
- Show where the analogy breaks. At that point, the intuition of the user will mislead them.
- State each guarantee exactly, with its limits. The session grades answers against these comparisons, so an overstated
  guarantee teaches a wrong rule.
- Do not force a comparison that is not honest. If a concept has no counterpart, say so plainly. "This one has no Java
  equivalent, which is why it feels alien" is useful for the user to hear.
